股票記帳 App MVP v3（自動股價＋USD/TWD）
=========================================

本版在 v2 已預載交易資料的基礎上新增：

1. 開啟 App 後自動更新目前持倉股價。
2. App 保持開啟時，每 15 分鐘再更新一次。
3. 自動更新 USD/TWD，目前使用 Yahoo Finance 的 TWD=X 行情。
4. 現價使用 Yahoo Finance 公開 chart 行情端點。
5. 若行情服務失敗，保留最後一次成功資料，不會清空價格。
6. 保留「立即更新全部」按鈕與手動覆寫價格功能。
7. 新增 USD 交易時，成交匯率欄會預填最新 USD/TWD；儲存後該交易的歷史匯率永久固定，不隨市場更新。
8. 持倉頁把未實現損益拆成「股價影響」與「匯率影響」，兩者相加約等於總未實現損益。

重要：
- 自動行情需要網路。
- Yahoo Finance 公開端點不是付費 SLA API，偶爾可能被限流或改版，所以 App 保留手動覆寫作為備援。
- 歷史成交價、成交匯率、手續費都不會被自動更新。
- 券商對帳單仍是最終正式憑證。
- App 資料仍存在瀏覽器 localStorage，請定期匯出 JSON。

PWA：
將整個資料夾放到 GitHub Pages / Cloudflare Pages 等 HTTPS 靜態網站後，用手機瀏覽器開啟並「加到主畫面」，即可像 App 使用。
